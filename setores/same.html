Perguntas Frequentes (FAQ)
Como solicitar cópia de prontuário para o paciente?▼
O paciente deve apresentar documento de identidade e preencher o formulário de autorização. O SAME disponibiliza a cópia em até 72h.
Qual o prazo para fechamento de prontuário após alta?▼
48h para o médico assinar o resumo de alta. Prontuários em aberto após esse prazo geram alerta automático.
Como corrigir erro de digitação no cadastro?▼
Acione o SAME pelo ramal 2800 ou presencialmente. Correções de dados sensíveis requerem documento comprobatório.
